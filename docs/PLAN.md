# GitHub 偵察機 - 實作步驟藍圖

## 從輸入到顯示照片的流程（小學生版）

想像你要找一個朋友的照片，整個過程就像寄快遞一樣：

---

### 第一關：你在輸入框打字（快遞員聽指令）

```
[你] → 打字「octocat」→ [電腦]
```

就像你跟快遞員說：「我要找一個叫小明的人！」

---

### 第二關：按下按鈕（快遞員出發）

```
[你] → 按「搜尋」按鈕 → [電腦說：出發！]
```

快遞員收到指令，準備出門去 GitHub 這個大圖書館找人。

---

### 第三關：電腦打電話給 GitHub（跨國電話）

```
[你的電腦] → 打電話給 GitHub →「我要找 octocat」
```

快遞員飛到美國，敲 GitHub 的大門：「有人嗎？我要找 octocat！」

---

### 第四關：GitHub 在資料庫翻找（大圖書館管理員）

```
[GitHub] → 資料庫搜尋 → 找到 octocat 的資料
```

管理員翻遍整個檔案櫃，發現：「找到了！他在第 888 號資料夾！」

---

### 第五關：GitHub 把資料傳回來（快遞員帶包裹回來）

```
[GitHub] → 寄出資料（名字、照片、粉絲數）→ [你的電腦]
```

GitHub 把 octocat 的頭像和基本資料打包成一個小包裹，快遞員帶回來。

---

### 第六關：電腦打開包裹、顯示在網頁上（拆禮物）

```
[你的電腦] → 收到包裹 → [網頁顯示：照片 + 名字 + 粉絲數]
```

快遞員把包裹交給你，你開心地把照片貼到網頁上給大家看！

---

## 實作檢查清單

### 階段一：基本頁面
- [ ] 建立專案（用 Vite 快速建立 Vue 3）
- [ ] 顯示一個輸入框
- [ ] 顯示一個按鈕

### 階段二：按下按鈕後
- [ ] 設定「當按鈕被點擊」的動作
- [ ] 讀取輸入框裡打的字
- [ ] 把拿到的名字存起來

### 階段三：打電話到 GitHub
- [ ] 學會「打電話」給別人的方法
- [ ] 把名字包裝成 URL 網址
- [ ] 發送請求到 GitHub

### 階段四：收到回應
- [ ] 等 GitHub 回話
- [ ] 打開 GitHub 寄來的包裹
- [ ] 把裡面的資料拿出來

### 階段五：顯示在網頁上
- [ ] 把照片顯示出來
- [ ] 把名字顯示出來
- [ ] 把粉絲數顯示出來
- [ ] 加上漂亮的樣式

## 技術對照表（給有經驗的人看）

| 步驟 | 現實比喻 | 技術名稱 |
|------|----------|----------|
| 把名字存起來 | 放進盒子 | 建立變數 |
| 讀取輸入框 | 從盒子拿出來 | 取 input value |
| 打電話到 GitHub | 快遞員出發 | fetch() API |
| 收到回應 | 包裹送達 | response.json() |
| 顯示照片 | 拆禮物 | 更新畫面 |
