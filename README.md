GitHub 偵察機 📡

這是一個使用 Vue 3 打造的 GitHub 用戶搜尋工具。透過與 AI 導師的對話，我學習了如何用白話邏輯來控制網頁的資料與顯示。

--------------------------------------------------------------------------------
📖 學習筆記：我如何看懂這些程式碼？

在開發過程中，我透過「審問」AI 導師來理解程式碼背後的魔法，以下是我的學習紀錄：

💡 關於記憶資料
我問了 AI：「程式碼裡的哪一行是負責『記住』我打的名字的？那一行長什麼樣子？」
AI 的比喻：ref() = 「盒子」。這是一個用來儲存資料的空間，就像在電腦裡準備一個盒子專門用來裝名字。

程式碼片段：
import { ref } from 'vue'
const searchName = ref('')

💡 關於自動同步
我問了 AI：「為什麼輸入框打字，盒子裡的資料就會跟著變？」
AI 的比喻：v-model = 「連接線」。它把輸入框與盒子連動，讓兩邊的內容自動保持一致。

程式碼片段：
<input v-model="searchName" />

💡 關於顯示邏輯
我問了 AI：「你是用哪一行指令來控制『查無此人』這行字『什麼時候該出現』的？」
AI 的比喻：v-if = 「開關」。這是一個控制邏輯，當找不到用戶時，它會打開開關讓錯誤訊息顯示出來。

程式碼片段：
<p v-if="errorMessage">查無此人</p>

--------------------------------------------------------------------------------
🔧 如何執行

安裝依賴：npm install
啟動開發伺服器：npm run dev
開啟網頁：請在瀏覽器打開 http://localhost:5173

--------------------------------------------------------------------------------
📁 檔案結構

src/App.vue：主要設計圖，包含「盒子」、「連線」與「開關」的邏輯。
docs/PLAN.md：存放與 AI 討論出的白話文步驟藍圖。
AGENTS.md：設定 AI 導師規則的保姆指令檔。

--------------------------------------------------------------------------------
📡 GitHub API 使用

本專案使用 GET https://api.github.com/users/{username} 抓取資料。
具備錯誤處理機制：若輸入不存在的名稱，會觸發「開關」顯示錯誤訊息，確保網頁不會毀損。
